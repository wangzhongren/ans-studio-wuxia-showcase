## 沟通要点
1. 武侠题材 Roguelike，硬性排除卡牌（无抽牌/出牌/手牌/牌组、无回合制卡牌对战）。
2. 大地图探索 + 自动攻击附近怪物，玩家操作聚焦移动走位。
3. 核心循环：击杀 → 掉落 → 拾取 → 升级成长；v2 在升级处加入三选一决策，但不改变即时战斗本质。
4. 后期目标：怪潮与范围清怪，达成「满屏清怪」的爽感。
5. v2 要求体验闭环：开始 → 门派选择 → 战斗 → 升级选择 → 结算 → 再来一局。
6. 桌面端可运行原型，双击/本地打开即可运行；素材生成在开发期离线完成，游戏运行时断网可用。
