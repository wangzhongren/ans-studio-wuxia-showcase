## 沟通要点
1. 武侠题材 Roguelike，硬性排除卡牌（无抽牌/出牌/手牌/牌组、无回合制卡牌对战）。
2. 大地图探索 + 自动攻击附近怪物，玩家操作聚焦移动走位。
3. 核心循环：击杀 → 掉落 → 拾取 → 升级三选一成长；即时战斗本质不变。
4. 后期目标：怪潮与范围清怪，达成「满屏清怪」的爽感。
5. 体验闭环：开始介绍页 → 门派选择 → 战斗 → 升级三选一 → 结算评分 → 再来一局。
6. 美术：本机 Qwen-Image-2.1 离线生成、放入项目 assets/ 并被实际引用；运行时零模型依赖、断网可玩；失败可保留占位但须如实记录。
7. 门派：剑宗（攻速）/ 刀门（爆发）/ 医谷（生存回复）三选一，初始属性与成长方向可观察。
8. AC-9~AC-13 必须在真实浏览器中人工目视验收。
