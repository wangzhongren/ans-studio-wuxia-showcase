# 江湖夜雨 · 武侠大地图 Roguelike 原型（wuxia-rogue）策划方案 v1

> 依据：`docs/product/wuxia-rogue-intent-v1.md`（intentId=`wuxia-rogue-map`，version 1）
> 模块清单：`docs/proposals/wuxia-rogue-modules-v1.md`（project-modules/v2）
> 人员名单：`docs/proposals/wuxia-rogue-roster-v1.md`（project-roster/v3）
> 架构契约：`docs/contracts/wuxia-rogue-architecture-v1.md`

## 1. 方案摘要

做一款**单机、桌面端、8 分钟一局**的武侠题材 Roguelike 原型：玩家在 3840×2160 的大地图上以 WASD 走位，角色自动对近身敌人放出剑气；击杀掉落银两/经验珠/疗伤丹，拾取后自动升级并变强；约 3 分钟后解锁范围技能、5 分钟解锁全屏大招，配合刷怪导演把同屏怪物推到 280 只以上，形成「满屏清怪」的爽感；8:00 存活即通关，死亡即结算。

**技术选型结论：HTML5 Canvas 2D + 原生 JavaScript（多文件经典脚本，无构建、无依赖、无网络），双击 `index.html` 或 `run.cmd` 即启动。**

**非卡牌保证（硬约束）**：全程不出现抽牌、手牌、牌组、构筑、卡面三选一等任何卡牌元素；升级为**自动数值成长**，结算界面只有数值统计。

## 2. 设计目标与边界

| 目标 | 落地方式 |
| --- | --- |
| 大地图可探索 | 3840×2160 世界、相机跟随+边界钳制、崖壁不可穿越但不卡人 |
| 自动攻击 | 170 px 索敌半径内最近目标自动放剑气，玩家只管走位 |
| 击杀→掉落→拾取→成长闭环 | 每只怪必掉经验珠，35% 掉银两，8% 掉疗伤丹；磁吸拾取 |
| 单局内可感知成长 | 8 分钟一局内从 Lv1 到 Lv12+，攻击力/攻速/剑气数量/范围技能逐级解锁 |
| 后期满屏清怪 | 刷怪导演按时间提密度，Lv3「剑气回旋」、Lv5「万剑归宗」范围清屏，配粒子/震屏/伤害数字 |
| 明确结束条件 | 8:00 存活=通关；HP 归零=失败；按 R 重开 |
| 后期帧率不崩 | 对象池 + 空间哈希 + 同屏硬上限 300 + 粒子/数字上限 + 离屏剔除 |

**不做**：卡牌任何形式、联机、存档云同步、剧情任务、移动端/手柄适配、商业化。

## 3. 技术选型

### 3.1 结论

采用 **HTML5 Canvas 2D + 原生 JavaScript（ES2019，经典 `<script>` 加载，全局命名空间 `WG`）**，零第三方依赖、零构建产物、零安装。

### 3.2 候选对比

| 方案 | 优点 | 缺点 | 结论 |
| --- | --- | --- | --- |
| **HTML5 + Canvas 2D + 原生 JS（无构建）** | 零依赖零安装；Windows 自带浏览器即运行时；调参改文件刷新即生效；2D 同屏数百实体完全够用 | 需自建循环/渲染/对象池，代码量略多 | **采用** |
| Phaser 3 | 引擎成熟、现成物理与动画 | 需 vendor 约 1.2 MB 库文件（离线环境获取成本高）；引擎抽象层增加调试与验收成本 | 备选（若后续要复杂动画再评估） |
| Python + pygame | 桌面原生窗口、素材处理方便 | 验收机需装 Python 与 pip 依赖，复现成本高，违背「一键运行」 | 否决 |

**理由**：本作核心是「大量简单 2D 实体 + 简单规则」，Canvas 2D 完全胜任；验收要求「桌面可运行、可复现」，零依赖方案把复现成本压到最低（双击即玩）。

### 3.3 运行方式

1. 解压/打开项目文件夹；
2. 双击 `index.html`（或双击 `run.cmd`，内部调用默认浏览器打开）；
3. 推荐 Edge / Chrome 近两年版本；无需联网、无需 Node、无需本地服务器；
4. 浏览器若限制 `file://` 加载（个别企业策略），备选：在该目录执行 `python -m http.server 8000`，访问 `http://localhost:8000/`。

脚本以经典 `<script defer>` 顺序加载（非 ES module），因此 `file://` 下无跨域问题。

## 4. 核心循环

```
开始 → 移动走位 → 自动攻击索敌 → 击杀怪物 → 掉落物落地 → 磁吸拾取
   ↑                                                        ↓
   └──────── 升级/解锁技能/属性成长 ← 经验累积 ←─────────────┘
                              ↓
                    怪潮密度上升 → 范围清屏 → 8:00 通关 / HP 归零失败 → 结算 → 重开
```

## 5. 系统设计

### 5.1 大地图与相机

- 世界尺寸 **3840×2160 px**；视口 1280×720（等比缩放适配窗口，最多放大 1.5×）。
- 地图为程序生成的开放原野：草地底纹 + 散落障碍（岩石、树、断墙）+ 4 个地标（破庙、石碑、枯井、竹林）。
- 障碍为圆形碰撞体（半径 18~40 px），玩家与怪物均绕行；**碰撞按 X/Y 轴分离求解**，贴墙滑动，不会被卡死在夹角。
- 世界四周为不可穿越崖壁：位置钳制在 `[margin, world - margin]`，保证 AC-1「不被边界卡死」。
- 相机跟随玩家（死区 120 px，平滑系数 8/s），相机钳制在世界边界内；玩家始终处于视口中心区。

### 5.2 移动与闪避

- WASD / 方向键八向移动，斜向归一化；基础移速 220 px/s。
- `Shift`/空格闪身：位移 120 px（0.16 s 内完成）、冷却 1.2 s、期间无敌 0.18 s；闪身不消耗资源。
- 移动是玩家唯一的核心操作；无鼠标瞄准、无点选目标。

### 5.3 自动攻击

- 索敌：每 0.1 s 缓存一次「170 px 内最近的存活怪物」（空间哈希查询），目标死亡/脱离 220 px 则重选。
- 攻击：间隔 0.55 s（受攻速成长影响），从角色朝向目标发射 1 道剑气（Lv8 起 2 道，间隔 18°）。
- 剑气：飞行速度 620 px/s，射程 340 px，伤害 12，穿透 1 个目标。
- 命中反馈：受击白闪 0.08 s + 伤害数字 + 轻微击退 8 px + 顿帧 2 帧（仅精英/击杀时）。
- 离开攻击范围后不再出手（满足 AC-2「离开范围后不再自动攻击」）。

### 5.4 怪物与刷怪导演

三类普通怪 + 一类精英：

| 怪物 | 行为 | 出现时间 |
| --- | --- | --- |
| 游侠（近战追击） | 直线追玩家，接触造成伤害 | 0 s 起 |
| 弓手（远程） | 保持 260 px 距离，每 1.8 s 射箭（速度 300 px/s） | 60 s 起 |
| 刀客（精英） | 蓄力 0.6 s 后直线冲锋 220 px，冷却 3 s | 每 60 s 起加入，最多 6 只 |
| 血刀宗师（可选 Boss） | 7:30 登场，HP 3000，扇形刀气 | 7:30（可延后版本） |

刷怪导演（Director）：

- 生成位置：玩家屏幕外环带 240~360 px 内随机点，避开障碍与屏幕可见区，**不贴脸刷怪**。
- 同屏目标数按时间线性插值：0 s=30 → 180 s=110 → 300 s=200 → 420 s=280；硬上限 **300**。
- 生成速率：目标缺口 × 1.2 /s（下限 1.6/s，上限 12/s），保证补怪不瞬间爆量。
- 难度：怪物 HP/伤害每分钟 +2%（+40% 封顶）；移速每分钟 +2 px/s（+14 封顶）。
- 每 60 s 触发一次「小高潮」：8 s 内生成速率 ×2，制造波次节奏。

### 5.5 掉落与拾取

- 击杀必掉 **经验珠（6 XP，精英 40 XP）**；35% 掉银两（1~3）；8% 掉疗伤丹（回复 25 HP）。
- 掉落物落地有 0.25 s 弹出动画（视觉），随后可拾取。
- 拾取半径 30 px；磁吸半径 80 px（每级 +2，上限 160），进入磁吸范围后以 260 px/s 飞向玩家。
- 拾取后：经验珠立即结算 XP 并消失；银两计入「银两」计数；疗伤丹立即回血。所有拾取均播放音效/粒子（占位）。
- 屏幕上常驻 HUD 显示：击杀数、拾取数、银两、等级、经验条（满足 AC-4「拾取数量可核对」）。

### 5.6 升级与成长曲线

- 升级曲线：`XP(n→n+1) = 40 + 24n`（n 从 1 开始），即 1→2 需 40，2→3 需 64，3→4 需 88……（约 4 分钟内到 Lv10）。
- **升级自动成长（无三选一卡面）**：每级 +2 攻击力、攻击间隔 ×0.97（下限 0.18 s）、拾取半径 +2、最大 HP +8 并回复 15 HP。
- 里程碑解锁：
  - **Lv3：剑气回旋** —— 环绕角色半径 95 px 的持续剑气，每 1.5 s 造成 18 伤害（范围伤害，清小怪主力）。
  - **Lv5：万剑归宗** —— 每 12 s 自动释放，半径 420 px 内全部敌人受 60 伤害并被击退 40 px，配全屏剑雨特效。
  - **Lv8：双剑气** —— 自动攻击同时发射 2 道剑气。
- 所有属性变化在 HUD 的「属性面板」（F3 详表）中实时可核对（满足 AC-5）。

### 5.7 后期怪潮与「满屏清怪」表现

- 密度：300 s 后同屏稳定 200+ 怪，420 s 后 280 只（硬上限 300）。
- 清屏手段：剑气回旋（持续范围）+ 万剑归宗（全屏爆发）+ 多道剑气，形成「一片一片消失」。
- 视觉反馈（性能受控）：
  - 击杀血雾粒子（每只 6 个，粒子上限 600，超出丢最旧）；
  - 伤害数字对象池（同屏上限 64，超出合并为「+N」聚合数字）；
  - 击杀精英/大招时屏幕震动（幅度 6 px，0.25 s）+ 短暂色差闪白；
  - 怪物死亡 0.12 s 缩放消失动画（走同一对象池，不新建对象）。
- 观感目标：进入 5 分钟后，玩家站着不动也能看到成片怪物被范围技能清掉（验收可观察证据）。

### 5.8 单局流程与结束条件

1. **标题界面**：标题 + 「按 Enter / 点击开始」+ 操作说明（WASD 移动、Shift 闪身、F3 性能面板）。
2. **对局**：8:00 倒计时，HUD 显示时间、等级、HP、经验、击杀数。
3. **结束**：
   - 8:00 到时存活 → **通关**（「血月退散」）；
   - HP ≤ 0 → **失败**（「力竭倒地」）；
   - 结算界面：存活时间、等级、击杀数、拾取数、银两、最终攻击力；按 R 重开。
4. 无暂停菜单以外的任何弹窗式卡牌选择。

### 5.9 性能预算与实现策略

| 预算项 | 目标 | 实测手段 |
| --- | --- | --- |
| 帧率 | 60 fps 目标，同屏 300 怪时 ≥ 45 fps | F3 面板显示 FPS 与 p95 帧耗时 |
| 单帧耗时 | 模拟 ≤ 6 ms，渲染 ≤ 8 ms（16.6 ms 预算） | `performance.now()` 分段计时 |
| 同屏实体 | 怪物 300 / 投射物 200 / 掉落 150 / 粒子 600 / 伤害数字 64 | F3 面板实体计数 |
| 内存 | 稳态无逐帧新对象分配（对象池复用） | Chrome 性能面板抽查 |

实现策略（写入架构契约，由 core-engine 落实）：

1. **固定步长模拟**：60 Hz 固定 dt（1/60）累加器 + 渲染插值，避免高刷屏逻辑漂移；单帧最多补 3 步防死亡螺旋。
2. **对象池**：怪物、剑气、敌方投射物、掉落、粒子、伤害数字全部预分配复用，容量到上限即复用最旧。
3. **空间哈希**：128 px 网格，怪物/掉落每帧重建（O(n)），索敌/碰撞只查 3×3 邻格。
4. **离屏剔除**：只绘制相机视野 + 96 px 余量的实体；粒子在视野外不绘制但仍计时。
5. **预渲染精灵**：角色/怪物/障碍在启动时绘制到离屏 canvas，运行时 `drawImage` 单次调用；避免逐帧 `shadowBlur`/渐变。
6. **渲染降级**：连续 2 s FPS < 50 时自动关闭屏幕震动与血雾粒子（可在 F3 查看降级状态），保证可玩。
7. **确定性**：mulberry32 种子随机（默认种子=时间，URL `?seed=1234` 可复现），所有刷怪/掉落/暴击走同一 RNG（满足 AC-8 可复现）。
8. **验收加速**：`?timescale=4` 时间加速（仅调试），`F4` 直接跳到 5:30 怪潮场景，`F5` 触发一次怪潮爆发，供验收快速复现 AC-6/AC-8。

### 5.10 非卡牌边界

- 界面元素：标题、HUD、结算，均为数值与文字，无卡面、无手牌区、无牌堆。
- 成长方式：自动数值成长 + 里程碑技能解锁，**不提供三选一/卡牌构筑选择**。
- 战斗方式：即时走位 + 自动攻击，无出牌/费用/回合。
- 验收对应 AC-7：完整游玩流程中不存在抽牌、出牌、手牌、牌组构筑任何元素。

## 8. 验收映射（AC-1 ~ AC-8）

| AC | 方案如何满足 | 可观察证据 |

| AC-1 地图可移动 | 3840×2160 世界 + 相机跟随 + 轴分离碰撞 | 走动可看到新区域；贴崖壁/障碍可滑动不卡死 |

## 9. 风险与对策

| 风险 | 影响 | 对策 |
| --- | --- | --- |
| 同屏 300 怪 + 粒子导致掉帧 | AC-6/AC-8 不达标 | 对象池+上限+离屏剔除+自动降级；F3 与 `tests/` 无头基准守门 |
| `file://` 下脚本加载受限（企业策略） | 无法双击运行 | 经典脚本无 CORS；备选 `python -m http.server`，写入 README |
| 升级选择被做成卡牌形态 | 违反 AC-7 | 明确自动成长，架构契约固化「无选择弹窗」 |
| 数值曲线过快/过慢，5 分钟到不了清屏 | 爽感不足 | 6.4 表格给基线，`?timescale` 与调试跳时快速调参 |
| 玩家被障碍夹角卡死 | AC-1 失败 | 轴分离碰撞 + 位置钳制 + 圆形碰撞体 |
| 素材缺失（无第三方版权素材） | 表现力不足 | 全部程序化绘制/占位几何图形，`assets/` 仅放自绘占位 |
